# Historical notes

These notes came from the standalone qf-tuner project before it was merged
into this repository. Paths, command names and future-stage proposals inside
them describe that historical design, not current requirements.
The former annotation stage described in these notes has been removed;
dataset producers prepare the required QF signals and rule verdicts upstream.

- `qf-tuner-design.md`: original project design.
- `tuner-notes.md`: early, unimplemented task-layout sketch.
- `labeling-provenance.md`: historical inference notes and completed-run locations.

Use the complete [repo guide](../../README.md) for current commands, contracts
and filter-version management.
